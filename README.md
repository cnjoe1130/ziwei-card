# 紫微斗数 · 十二宫分享卡

输入生日时辰，生成一张 1080×1440 的紫微斗数分享卡，并给出十二宫白话速读与双人合盘。

在线使用：https://cnjoe1130.github.io/ziwei-card/

## 边界

- 内容为文化叙事，不做吉凶预测，不含大限、流年、评分。
- 排盘与文案生成全部在浏览器本地完成，没有后端，不收集、不保存生日。
- 判词覆盖 39 种命宫主星组合（含命无正曜）；四化落在辅星时只标宫位。

## 本地运行

ES module 不能用 `file://` 直接打开，需要起一个静态服务：

```bash
python -m http.server 8123
```

然后打开 http://127.0.0.1:8123/

## 部署

仓库根目录就是站点，无构建步骤。GitHub Pages 选择 `main` 分支、`/` 根目录即可。

## 文件

- `index.html` — 页面结构
- `styles.css` — 宣纸/墨/朱砂视觉
- `app.js` — 交互、盘面渲染、导出与分享
- `ziwei.js` — 农历换算与排盘
- `content.js` — 39 种命宫判词
- `explain.js` — 十二宫白话、四化与合盘文案
- `vendor/html-to-image.js` — 卡面导出

排盘口径：农历月定命宫，闰月十五后按下月，23:00 后按次日子时；只绘十四主星。
